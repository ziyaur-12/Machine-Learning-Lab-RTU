# 📘 Theory

Artificial Neural Network (ANN) is a computational model inspired by the human brain.

Backpropagation is a supervised learning algorithm used for training multi-layer neural networks.

The algorithm works in two phases:

1. Forward Propagation
2. Backward Propagation

---

# ⚙ Working of Backpropagation

## 🔹 Forward Pass

- Inputs are passed through hidden layer
- Activation function is applied
- Output is generated

## 🔹 Backward Pass

- Error is calculated
- Gradients are computed
- Weights are updated
